## النظام الوطني لإدارة مؤشرات الأداء الصحي والجودة وسلامة المرضى في اليمن

**الإصدار:** 1.0 — المرحلة الأولى · **الحالة:** مسودة بانتظار الموافقة

---

## الشرح بلغة بسيطة
هذه الوثيقة تشرح **ماذا يرى المستخدم ويفعل** في كل من البرنامج المحلي والمنصة المركزية، خطوة بخطوة، دون الدخول في تفاصيل الكود.

# الجزء الأول: تطبيق سطح المكتب (Windows)

## 1. أول تشغيل
1. يفتح المستخدم البرنامج → شاشة عربية RTL.
2. **التهيئة الأولى:** إدخال اسم المستشفى، المحافظة، رمز المستشفى، ثم ربط الجهاز بالخادم (رابط + مفتاح تفعيل) مرة واحدة.
3. إن لم يتوفر إنترنت: يمكن التهيئة **دون اتصال** والعمل فوراً، ويُزامَن الربط لاحقاً.
4. إنشاء حساب مدير المستشفى المحلي بكلمة مرور.

## 2. تسجيل الدخول
- شاشة دخول بسيطة (اسم مستخدم + كلمة مرور).
- عند انقطاع الإنترنت: يعمل **الدخول المحلي** ببيانات محفوظة ومُشفّرة.
- قفل تلقائي بعد فترة خمول، وقفل الحساب بعد محاولات فاشلة متكررة.

## 3. الشاشة الرئيسية (لوحة المستشفى)
- بطاقات: المؤشرات المكتملة/الناقصة، الفترات المفتوحة، الحوادث المفتوحة، CAPA المتأخرة.
- **شريط حالة المزامنة:** متصل/غير متصل، آخر مزامنة، عدد العناصر غير المُزامَنة، أخطاء.
- اختصارات: إدخال مؤشرات، مراجعة، حوادث، تقارير.

## 4. شاشات الإدخال
### 4.1 إدخال مؤشر
- اختيار القسم → اختيار المؤشر → اختيار الفترة.
- إدخال البسط والمقام (إن انطبق) أو القيمة المباشرة.
- **الحساب الفوري** للنتيجة + مقارنتها بالهدف والحدود المقبولة.
- تنبيه إذا كانت القيمة شاذة (خارج نطاق منطقي) — يُسمح بالإدخال مع تسجيل تنبيه وسبب.
- إرفاق ملاحظة/مصدر.
- أزرار: **حفظ مسودة** / **إرسال للمراجعة**.

### 4.2 جدول الإدخال السريع
- جدول يضم كل مؤشرات قسم لفترة واحدة → إدخال سريع بصفوف، مع مؤشر اكتمال لكل صف.

## 5. شاشة المراجعة والاعتماد
- قائمة الفترات المُرسَلة → فتح فترة → عرض القيم ومصادرها → اعتماد الكل أو إعادة عناصر محددة بتعليق.
- من أدخل لا يستطيع اعتماد إدخاله (فصل المهام).

## 6. شاشة الجودة وسلامة المرضى
- **الحوادث:** نموذج إبلاغ (تصنيف، خطورة، وصف، إبلاغ سرّي اختياري) + قائمة ومتابعة الحالة.
- **RCA:** فتح حادث → تشكيل فريق → تسلسل الأحداث → الأسباب الجذرية → توليد CAPA.
- **CAPA:** جدول الإجراءات (مسؤول، موعد، حالة) + عرض المتأخر.
- **المخاطر:** سجل المخاطر + مصفوفة (احتمال×أثر).
- **التدقيق:** قائمة تحقق → نتائج → إجراءات.
- **خطط التحسين / الوثائق / الاجتماعات:** شاشات إدارة ومتابعة.

## 7. شاشة التقارير
- اختيار التقرير (شهري/سنوي/مخصص) → اختيار المؤشرات والفترات → معاينة → **تصدير PDF/Excel** (عربي RTL) → طباعة.

## 8. شاشة المزامنة
- حالة الاتصال، آخر مزامنة، **قائمة ما لم يُزامَن**، سجل الأخطاء مع سبب واضح، زر **مزامنة الآن**.
- سجل التعارضات (إن وُجدت) وكيف حُلّت.

## 9. شاشة النسخ الاحتياطي
- **نسخ احتياطي الآن** → يُنشئ ملفاً مضغوطاً مشفّراً.
- **استعادة** → اختيار ملف → تحقق من السلامة → تحذير → استعادة.
- جدولة نسخ دورية تلقائية (مثلاً يومياً) إلى مجلد محلي أو وحدة تخزين خارجية.

## 10. متطلبات الجهاز (مقترحة، تُضبط عند التنفيذ)

# الجزء الثاني: المنصة المركزية (Web Portal)

## 11. تسجيل الدخول والصلاحيات
- دخول آمن؛ كل شاشة **مُقيَّدة بالصلاحية على الخادم**.
- الإدارة المركزية ترى كل المستشفيات؛ مسؤول المحافظة يرى محافظته؛ المستشفى يرى نفسه.

## 12. لوحة القيادة الوطنية
- مؤشرات وطنية مُجمَّعة، خريطة/جدول مقارنة المحافظات، أعلى/أدنى المستشفيات أداءً، المؤشرات المتعثرة وطنياً.
- فلترة بالزمن، المؤشر، المحافظة، نوع المستشفى.

## 13. المقارنات
- مقارنة مستشفى بمستشفى، محافظة بمحافظة، وقيمة مقابل الهدف والاتجاه.

## 14. متابعة التقارير الشهرية/السنوية
- جدول يوضح من أرسل ومن تأخّر، ونسبة الاكتمال، وحالة الاعتماد.

## 15. إدارة المستشفيات والأقسام والمستخدمين
- إضافة/تعديل المستشفيات والأقسام، تعيين المسؤولين، إدارة المستخدمين والأدوار.

## 16. مكتبة المؤشرات الوطنية
- إنشاء مؤشر وطني → نشر إلى المستشفيات → إصدارات جديدة لا تُفسد التاريخ.

## 17. التقارير المجمّعة
- استخراج تقارير وطنية/محافظة/مستشفى، وتصدير PDF/Excel.

## 18. متابعة المتأخرين
- قائمة المستشفيات المتأخرة في الإرسال مع الإشعارات.

## 19. مركز التنبيهات
- تنبيهات المؤشرات المتجاوزة للحدود أو المتأخرة أو الشاذة، مع أساس التنبيه.

## 20. الإدارة والإعدادات
- إدارة النسخ الاحتياطي المركزي، سجل التدقيق، إعدادات النظام، قنوات الذكاء الاصطناعي.

---

## 21. رحلة عمل نموذجية (من القسم إلى القيادة)
```
مسؤول القسم يدخل قيمة  →  النظام يحسب ويقارن بالهدف  →  مدير الجودة يراجع ويعتمد
   →  تُثبَّت محلياً  →  عند الاتصال تُزامَن للخادم  →  تظهر في لوحة المستشفى
   →  تُجمَّع مركزياً  →  تظهر في لوحة القيادة الوطنية  →  تنبيه إذا تجاوزت الحد
```

## 22. مبادئ تجربة المستخدم (UX)
- **عربي أولاً، RTL كامل،** أرقام واضحة، مصطلحات بسيطة.
- **أقل عدد نقرات** للمهام المتكررة (إدخال، اعتماد).
- **حالة النظام دائماً ظاهرة** (متصل/غير متصل، ما لم يُزامَن).
- **لا رسائل خطأ غامضة:** كل خطأ يوضح السبب والخطوة المقترحة.
- **تلميحات داخلية** لغير المتخصصين، ودليل استخدام عربي مدمج.

## 23. الوصول والصلاحيات في الواجهة
- الواجهة تُخفي ما لا يملكه المستخدم **بالإضافة إلى** منعه على الخادم (الدفاع بطبقتين).
- أي محاولة وصول غير مصرّح بها تُرفض وتُسجَّل.
