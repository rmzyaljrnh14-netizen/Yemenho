# محرّك حساب المؤشرات (تفصيلي)
## النظام الوطني لإدارة مؤشرات الأداء الصحي والجودة وسلامة المرضى — وزارة الصحة العامة والسكان

**الإصدار:** 1.1 · **الحالة:** مسودة بانتظار الموافقة

---

## الشرح بلغة بسيطة
محرّك الحساب هو **الآلة الحاسبة** التي تحوّل ما يدخله الموظف (أرقام البسط والمقام أو قيمة) إلى **نتيجة مؤشر** وتقييمها مقابل الهدف. هذه الوثيقة تحدّد القواعد بدقة حتى تُحسب كل المؤشرات بنفس الطريقة في كل اليمن.

---

## 1. أنواع المؤشرات (Taxonomy)
| النوع (`calc_type`) | الوصف | المعادلة |
|--------------------|-------|----------|
| `ratio` | نسبة مئوية | (بسط ÷ مقام) × 100 |
| `rate` | معدل لكل N | (بسط ÷ مقام) × N (مثلاً 1000) |
| `count` | عدد صحيح | القيمة كما هي |
| `average` | متوسط | مجموع ÷ عدد |
| `composite` | مركّب مرجّح | Σ (مؤشر فرعي × وزن) ÷ Σ أوزان |
| `target_value` | قيمة تُقارَن بهدف | القيمة كما هي |
| `scale` | مقياس/درجة | القيمة على مقياس محدّد |

## 2. وحدات القياس (`unit`)
- `percent` (%)
- `per_1000` / `per_10000` / `per_100000`
- `count`
- `days` / `hours` / `minutes`
- `score` (مقياس)
- `ratio` (نسبة غير مئوية)

## 3. اتجاه التحسن (`direction`)
| القيمة | المعنى | مثال |
|-------|--------|------|
| `higher_better` | الأعلى أفضل | الالتزام بنظافة اليدين |
| `lower_better` | الأدنى أفضل | معدل العدوى، الحوادث |
| `closer_to_target` | الأقرب للهدف أفضل | استهلاك مضادات حيوية |

**قاعدة التقييم:** التقييم (`better/worse/stable`) **يعتمد على `direction`**؛ لا يُفترض أن الارتفاع جيد.

## 4. قواعد الحساب الدقيقة
### 4.1 نسبة/معدل
```
if denominator is null or denominator == 0:
    result = incomplete   # لا تُخترع قيمة
else:
    result = (numerator / denominator) * multiplier
```
- `multiplier` = 100 لنسبة، 1000/10000/100000 للمعدل.
- **التقريب:** يُحفظ بدقة عالية (مثلاً 4 منازل) ويُعرض بمنزلتين افتراضياً.

### 4.2 متوسط
```
if count is null or count == 0: result = incomplete
else: result = sum / count
```

### 4.3 عدد/قيمة
```
result = raw_value   # بلا تحويل
```

### 4.4 مركّب
```
result = Σ(sub_value_i * weight_i) / Σ(weight_i)
# يُشترط وجود كل المؤشرات الفرعية المطلوبة؛ إن نقص أحدها → incomplete
```

## 5. تقييم مقابل الهدف والحدود
```
target        = indicator_version.target_value
acceptable_min= indicator_version.acceptable_min
acceptable_max= indicator_version.acceptable_max
```
| الحالة | الشرط |
|-------|-------|
| `within_target` | ضمن الحدود المقبولة |
| `above_max` | أعلى من الحد الأعلى |
| `below_min` | أدنى من الحد الأدنى |
| `at_target` | عند الهدف |
| `no_target` | لا هدف مُعرَّف (يُعرض الرقم فقط) |

**التفسير حسب الاتجاه:**
- `lower_better` + `above_max` → **تحذير** (سوء أداء).
- `higher_better` + `below_min` → **تحذير**.
- `closer_to_target` → المسافة عن الهدف هي المعيار.

## 6. كشف القيم الشاذة (Validation)
### 6.1 على مستوى الإدخال
- نوع القيمة (رقم)، عدم السلبية حيث يلزم.
- المقام > 0 لمؤشرات النسبة/المعدل.
- القيمة داخل نطاق منطقي مطلق (مثلاً نسبة ≤ 100%).

### 6.2 على مستوى التسلسل الزمني
- **انحراف كبير عن المتوسط التاريخي:** يُحسب (Z-score) مقابل آخر N فترات؛ إن تجاوز حداً → تنبيه.
- **قفزة/هبوط مفاجئ:** تغيّر نسبي يتجاوز عتبة (مثلاً > 50%) → تنبيه.
- **قيمة صفرية غير متوقعة** حيث المعتاد > 0 → تنبيه.

**قاعدة:** التنبيه **لا يمنع** الإدخال؛ يُسجَّل السبب ويُعلَّم السجل. **لا اختلاق ولا رفض صامت.**

## 7. حساب الاتجاه (Trend)
```
trend = compare(current_value, previous_value, direction)
# up | down | stable (ضمن هامش تغيّر صغير)
```
- الهامش (`stability_threshold`) قابل للضبط لكل مؤشر.
- يُعرض الاتجاه بمعنى الأداء (تحسّن/تراجع) لا بمجرد صعود/هبوط.

## 8. التجميع (Aggregation) — مهم وطنياً
عند تجميع قيم من أقسام إلى مستشفى إلى محافظة إلى وطن:
- **النسب والمعدلات:** **لا تُجمَّع بالمتوسط البسيط**؛ تُجمَّع بجمع البسط والمقام ثم إعادة الحساب.
  ```
  aggregate_ratio = (Σ numerator) / (Σ denominator) * multiplier
  ```
- **الأعداد:** تُجمع.
- **المتوسطات:** تُحسب مرجّحة بالعدد (weighted).
- **المركّبة:** تُحسب من مكوّناتها المُجمّعة.

> هذه قاعدة جوهرية: تجميع النسب خطأً بالمتوسط يُشوّه الصورة الوطنية. النظام يمنعه.

## 9. الإصدارات (Versioning) وحماية التاريخ
- كل مؤشر له **إصدارات** (`indicator_versions`).
- البيانات التاريخية مرتبطة **بإصدار المؤشر وقت الإدخال**.
- تعديل تعريف المؤشر → إصدار جديد؛ **لا يُعاد حساب التاريخ** تلقائياً (إلا بإجراء صريح موثّق).
- إذا لزم إعادة الحساب: يُنشأ **سجل إعادة حساب** يوضّح من ومتى وعلى أي إصدار.

## 10. محرّك الصيغ (Formula Engine)
- المؤشرات البسيطة تُعرَّف بالبسط/المقام بلا كود.
- المؤشرات المركّبة أو المعقّدة: **تعبير رياضي آمن** (قائمة عمليات محدودة: +، −، ×، ÷، أقواس، دوال مسموحة) — **لا تنفيذ كود حر** (منعاً للثغرات).
- التحقق من صحة التعبير عند الحفظ (لا مراجع مفقودة، لا قسمة على ثابت صفر).

## 11. واجهة المستخدم للحساب
- عند الإدخال: تُعرض **النتيجة فوراً** + الوحدة + المقارنة بالهدف + الاتجاه.
- **مؤشر اكتمال** لكل مؤشر (مُدخل/ناقص).
- **شرح الحساب** متاح للمستخدم (كيف حُسب الرقم).

## 12. سجل الحساب (Auditability)
لكل قيمة محسوبة يُخزَّن:
- المدخلات (بسط/مقام/قيمة).
- الإصدار المستخدم.
- الناتج والوحدة.
- من أدخل ومتى، ومن اعتمد ومتى.
- أي أعلام (شذوذ) ومبرّراتها.

## 13. حالات حدّية (Edge Cases)
| الحالة | السلوك |
|-------|-------|
| مقام = 0 | `incomplete` + رسالة "لا يمكن القسمة على صفر" |
| بسط > مقام لنسبة | يُحسب لكن يُنبَّه (قد يكون خطأ إدخال) |
| قيمة سالبة | مرفوضة (إلا لمؤشرات فرق مُعرَّفة) |
| فترة ناقصة | تُعلَّم ناقصة؛ لا تُختلق |
| مؤشر بلا هدف | يُعرض الرقم دون تقييم |
| مؤشر مركّب ناقص مكوّن | `incomplete` |
| تعديل إصدار المؤشر | بيانات قديمة تبقى على إصدارها |

## 14. اختبارات محرّك الحساب (إلزامية)
- كل نوع حساب بحالات صحيحة وحدّية.
- اتجاه تنازلي (عدوى/حوادث): التأكد أن الانخفاض يُقيَّم كتحسّن.
- تجميع النسب: مقارنة الحساب المُجمَّع بالحساب اليدوي الصحيح.
- المتوسطات المرجّحة.
- المركّبة بأوزان.
- المقام صفر.
- الشذوذ: كشف القيم المتطرفة دون منع الإدخال.
- الإصدارات: تعديل مؤشر لا يغيّر نتائج تاريخية.

## 15. قواعد ذهبية
- **لا قيمة مُختلقة؛ نقص المدخلات = `incomplete`.**
- **اتجاه التحسن يحكم التقييم.**
- **تجميع النسب بجمع البسط والمقام، لا بالمتوسط.**
- **التاريخ محميّ بالإصدارات.**
- **كل حساب قابل للتفسير والتدقيق.**

| البند في الوثيقة | المنفَّذ في v0.4 |
|------------------|------------------|

| `closer_to_target` | `target_range` (نطاق مستهدف بحدّين) |
| `composite` (مركّب مرجّح) | **لم يُنفَّذ بعد** — مؤجَّل |
| `incomplete` | يُعاد `null` للقيمة، ويُقيَّم كـ `unknown` |
| التقريب | 4 منازل (ROUND_HALF_UP) |
| المقام صفر | قيمة `null` بلا قسمة على صفر |
| التقييم | `good` · `warning` · `poor` · `unknown` حسب الاتجاه والحدود |
| الاتجاه | `higher_better` · `lower_better` · `target_range` |

القاعدة محفوظة: **لا قيمة مُختلقة؛ أي نقص في المدخلات يعطي قيمة فارغة وتقييماً `unknown`.**
