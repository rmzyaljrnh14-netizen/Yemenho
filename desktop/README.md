# تطبيق سطح المكتب (Desktop) — v0.6

النظام الوطني لإدارة مؤشرات الأداء الصحي والجودة وسلامة المرضى — وزارة الصحة العامة والسكان.

تطبيق سطح المكتب مبني بـ **Tauri 2 + React 18 + TypeScript**، بواجهة عربية كاملة (RTL).

## ما تم تنفيذه فعلياً (ومُختبر)

### v0.2
- **هيكل التطبيق:** Tauri 2 (غلاف سطح المكتب) + Vite + React + TypeScript.
- **واجهة عربية RTL** كاملة مع ثيم موحّد.
- **تسجيل الدخول** وربط فعلي بالخادم الخلفي عبر REST + JWT، مع تجديد الرمز تلقائياً.
- **إخفاء الواجهات حسب الصلاحية:** لا تظهر شاشات «المستخدمون» و«الهيكل الإداري» و«سجل التدقيق» إلا لمن يملك صلاحيتها.
- **الشاشات:** لوحة المعلومات · المستشفيات والأقسام · الهيكل الإداري · المستخدمون · سجل التدقيق.
- **إثبات العزل في الواجهة:** مستخدم المستشفى يرى مستشفاه فقط (تحقّق فعلي عبر المتصفح).

### v0.4
- **مكتبة المؤشرات:** عرض الـ 25 مؤشراً، بحث، وتفاصيل كل مؤشر (التعريف، طريقة القياس، الاتجاه، الهدف، الحدود).
- **إدخال بيانات المؤشرات:** اختيار المستشفى والفترة، إدخال البسط والمقام (أو قيمة مباشرة)، وحساب النتيجة تلقائياً مع تقييمها مقابل الهدف.
- **التمييز بين المؤشرات على مستوى المستشفى وعلى مستوى الأقسام** في نفس الشاشة.
- **دورة العمل من الواجهة:** إرسال للمراجعة · مراجعة · اعتماد · إعادة للتعديل، مع تعطيل التعديل عند تجميد الفترة.

### v0.5
- **صفحة «التقارير ولوحات المعلومات»:** لوحة وطنية مجمّعة، مقارنة المستشفيات والمحافظات، تقرير مستشفى تفصيلي، واتجاه المؤشرات الزمني.
- **رسوم بيانية بـ ECharts:** أعمدة أفقية للمقارنة، خطّي للاتجاه مع خط الهدف، ودائري لتوزيع التقييمات.
- **تصدير Excel وPDF بالعربية** مباشرة من الواجهة (تنزيل فعلي للملف).
- **الصفحة تُحمَّل عند الطلب (lazy)** لتبقى الحزمة الأساسية صغيرة.
- **احترام الصلاحيات:** مستخدم المستشفى يرى تقرير مستشفاه فقط، واللوحة الوطنية تظهر للإدارة المركزية ومكاتب الصحة.

### v0.6 — العمل دون إنترنت والمزامنة (الجزء المحلي)
- **قاعدة بيانات محلية SQLite:** تخزين آمن على الجهاز (`rusqlite` مع `bundled`)، يبقى سليماً بعد إغلاق التطبيق أو انقطاع الكهرباء.
- **العمل دون إنترنت:** عند تعذّر الوصول للخادم، تُبنى شاشة إدخال البيانات من الذاكرة المؤقتة المحلية (المؤشرات، الإسنادات، الأقسام، الفترات)، ويُحسب التقييم محلياً بنفس قواعد الخادم.
- **صندوق صادر (Outbox):** كل حفظ دون إنترنت يُسجَّل عمليةً بمعرّف فريد؛ إعادة الإرسال لا تُكرّر السجل.
- **محرّك المزامنة:** يدفع العمليات المعلّقة ثم يسحب تغييرات الخادم بعد مؤشّر محفوظ، تلقائياً عند التشغيل وكل دقيقة وعند عودة الاتصال.
- **صفحة «المزامنة والنسخ الاحتياطي»:** حالة الاتصال، آخر مزامنة، عدد العمليات المعلّقة والمتعذّرة، التعارضات، وزر «مزامنة الآن».
- **مؤشّر مزامنة في الشريط العلوي:** «مُزامن» / «معلّق: n» / «دون إنترنت» مع رابط مباشر للصفحة.
- **النسخ الاحتياطي المحلي:** تنزيل ملف JSON يحتوي المكتبة والعمليات المعلّقة.
- **10 اختبارات Rust تنجح** (الحساب، التقييم، الصندوق الصادر، التعارض، البقاء بعد إعادة الفتح).

### v0.9 — مركز التنبيهات
- **صفحة «مركز التنبيهات»:** قائمة تنبيهات محسوبة على الخادم من البيانات الفعلية (تأخر الإرسال، تدنّي تحقيق الأهداف، ضغط الجودة وسلامة المرضى، اتجاهات المؤشرات)، مع بطاقات ملخّص وفلترة بالسنة والشهر.
- **الإقرار وإعادة الفتح:** لمن يملك صلاحية `alert.manage`، مع حفظ من أقرّ ومتى وبأي ملاحظة.
- **يحتاج اتصالاً بالشبكة** (يُحسب على الخادم المركزي)؛ باقي التطبيق يواصل العمل دون إنترنت.

### v0.10 — تهيئة عتبات التنبيه
- **زر «تهيئة عتبات التنبيه»** داخل صفحة مركز التنبيهات (لمن يملك `alert.configure`).
- **جدول العتبات:** كل نوع مع قيمه الفعلية وحقول رقمية و«حفظ» و«استرجاع الوطني»، وحالة التخصيص (وطني/مستشفى).
- **التدقيق في الخادم:** القيم تُقصّ لنطاقاتها والمفاتيح المجهولة تُتجاهل، فلا يُعطّل تعديل خاطئ المحرّك.
- **يحتاج اتصالاً بالشبكة** (التهيئة تُحفظ على الخادم المركزي).

### v0.11 — سجل التدقيق
- **صفحة «سجل التدقيق»:** بطاقة تصفية (نوع الكيان، الإجراء، المستخدم، من/إلى تاريخ، بحث)، وجدول بالوقت والمستخدم والملخّص والإجراء، مع زر «تفاصيل» يعرض قبل/بعد.
- **ترقيم:** السابق/التالي مع عرض «المعروض س–ص من المجموع».
- **تصدير:** إلى Excel وCSV وفق التصفية نفسها.
- **يقتصر على نطاقك:** مستخدم المستشفى يرى مستشفاه فقط (عزل RLS)، والسجل للقراءة فقط.
- **يحتاج اتصالاً بالشبكة** (يُقرأ من الخادم المركزي).

## المتطلبات

- Node.js 20+ و npm.
- Rust (stable) عبر `rustup`.
- على Linux: حِزم الويب فيو (`libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `librsvg2-dev`, `patchelf`).
  على Windows: WebView2 (مضمّن في Windows 10/11 حديثاً).

## التشغيل

```bash
# الخادم الخلفي أولاً (من مجلد المشروع)
bash backend/run.sh

# ثم التطبيق
cd desktop
npm install
npm run tauri dev      # وضع التطوير (يفتح نافذة سطح المكتب)
npm run tauri build    # إنتاج ملفات التثبيت (Windows: .msi / .exe)
```

للتشغيل في المتصفح فقط (بدون Tauri) أثناء التطوير:

```bash
cd desktop && npm run dev      # http://127.0.0.1:5173
```

## الفحص والبناء

```bash
npm run typecheck      # فحص الأنواع TypeScript
npm run build          # بناء الواجهة
cargo build --manifest-path src-tauri/Cargo.toml --release   # بناء غلاف سطح المكتب
```

## بنية المشروع

```
desktop/
  index.html
  src/
    api.ts         عميل REST (JWT + تجديد تلقائي) — يشمل واجهات المزامنة
    desktop.ts     جسر Tauri إلى المخزن المحلي (SQLite)
    sync.ts        محرّك المزامنة (دفع ثم سحب)
    useSync.ts     ربط المزامنة بالواجهة (مؤقّت + أحداث الاتصال)
    auth.tsx       سياق المصادقة والصلاحيات
    App.tsx        المسارات
    Shell.tsx      الهيكل الجانبي
    styles.css     الثيم العربي RTL
    types.ts       الأنواع
    reports.ts     أدوات عرض التقارير (تسميات، ألوان، تنسيق أرقام)
    components/    مكوّنات مشتركة (غلاف ECharts)
    pages/         الشاشات (تسجيل الدخول، اللوحة، مكتبة المؤشرات، إدخال البيانات، التقارير، المستشفيات، الهيكل، المستخدمون، التدقيق، المزامنة)
  src-tauri/
    src/store.rs   المخزن المحلي SQLite + الصندوق الصادر + المزامنة
    src/lib.rs     أوامر Tauri المُتاحة للواجهة
    tauri.conf.json
    icons/         الأيقونات
  scripts/make_icons.py
```

## ما لم يُنفَّذ بعد (بصراحة)

- المنصة المركزية — **v0.3**.
- **مزامنة بقية وحدات الجودة** (CAPA، المخاطر، التدقيق…) — المزامنة دون إنترنت مُنفَّذة للمؤشرات والحوادث فقط.
- **المساعد الذكي ومركز التنبيهات يعملان عبر الخادم** (يحتاجان اتصالاً)؛ لا تحليل محلي دون إنترنت.
- **إشعارات فورية** عند ظهور تنبيه جديد (القائمة تُسحب عند الفتح فقط).
